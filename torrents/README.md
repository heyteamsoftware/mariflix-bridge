Sube aquí los `.torrent` directamente desde GitHub (botón "Add file" → "Upload files" en esta carpeta).

- Un `.torrent` suelto aquí = una PELÍCULA
- Una carpeta = una SERIE
  - `.torrent` directamente dentro = "Temporada 1"
  - subcarpetas dentro = una temporada cada una

Ejemplo:
```
torrents/Interstellar.torrent
torrents/Breaking Bad/Cap1.torrent
torrents/Breaking Bad/Temporada 2/Cap1.torrent
```

Después de subir, Render redespliega solo en 1-2 minutos y el catálogo se actualiza automáticamente.
